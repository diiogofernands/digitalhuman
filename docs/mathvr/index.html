Abstract

MathVR is an extended reality system for immersive mathematics learning featuring an LLM-driven tutor capable of answering questions and explaining concepts. Existing XR applications often enhance visualization but lack adaptive conversational guidance. MathVR addresses this gap through multimodal interaction: learners engage via speech and handwritten sketches within a shared virtual workspace, while the tutor dynamically projects visual information onto a whiteboard through a tagging mechanism, creating synchronized verbal and visual guidance. Unlike traditional digital tutors, the conversational agent employs guided discovery and scaffolding strategies rather than delivering direct solutions. Preliminary user feedback from 12 participants indicates increased engagement and perceived clarity, highlighting the feasibility of adaptive multimodal dialogue in immersive learning.

Why MathVR

Guided Discovery, Not Direct Answers

The system prompt encodes scaffolding strategies aligned with Vygotsky's Zone of Proximal Development: the tutor delivers targeted hints and partial steps, encouraging independent reasoning rather than passive reception.

Synchronized Verbal and Visual Guidance

A whiteboard-tag mechanism extracts <<>>-delimited content from the LLM's responses and projects it as live annotations, combining speech and diagram in a single coherent explanation following dual-coding principles.

Sketch-Aware Tutor

Learner handwriting on a virtual desk sheet is continuously captured and sent alongside transcribed speech, allowing the tutor to incorporate the student's own drawings into its reasoning and responses.

Method

  1. Learner speech is transcribed in real time by OpenAI Whisper; handwritten sketches from a virtual desk sheet are captured continuously and forwarded alongside the transcript.
  2. A conversational module based on Google ADK conditions Gemini 2.5 Flash with a scaffolding-based pedagogical prompt that prioritizes stepwise reasoning and deferred full solutions.
  3. A callback module scans the model output for whiteboard tags; tagged content is extracted and rendered live on the shared virtual whiteboard, maintaining synchronized visual and verbal guidance.
  4. Tag validity is enforced with regex-based validation; malformed tags are corrected programmatically or repaired via a secondary API call using the surrounding conversational context.
  5. The model's response text is synthesized by ElevenLabs TTS and delivered through a MetaHuman digital tutor avatar, closing the multimodal interaction loop.

Interaction Loop

speech + sketch -> Whisper

-> Gemini 2.5 Flash (ADK)

-> tag callback -> whiteboard

-> ElevenLabs TTS -> avatar

The whiteboard projection and voice delivery are decoupled: tag detection controls visual output independently from the verbal TTS response.

Contributions

Multimodal tutoring loop in VR

A closed interaction loop integrating speech recognition (Whisper), sketch capture, LLM-driven scaffolding (Gemini 2.5 Flash via ADK), and TTS delivery (ElevenLabs) within a single coherent VR session.

Whiteboard-tag mechanism

A structured output protocol that enables the LLM to project synchronized visual annotations onto a shared whiteboard mid-response, combining verbal and spatial explanation in real time.

Scaffolding over direct answers

The pedagogical prompt encodes guided discovery principles, keeping the tutor from giving away solutions and instead prompting incremental reasoning aligned with ZPD and active learning frameworks.

Domain-agnostic architecture

Although focused on mathematics, the system is designed for any discipline that depends on conceptual reasoning and visual representation, including physics, chemistry, and language learning.
