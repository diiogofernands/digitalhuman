From Cards to Creatures: Interactive 3D Generation using GenAI

A mobile AR system that transforms physical trading cards into interactive 3D creatures by decoupling real-time card detection from offline generative 3D production, enabling consistent, low-latency rendering without external markers or proprietary SDKs.

Abstract

From Cards to Creatures is a mobile augmented reality system that enables interactive 3D visualization of physical trading cards through generative AI. The pipeline combines object detection, retrieval, and image-to-3D generation to support real-time rendering anchored to physical inputs. A YOLOv11-based detector identifies and extracts the card's unique ID from the mobile camera feed; PaddleOCR reads the set and collector number from the localized region of interest. This ID enables instant retrieval of a corresponding 3D asset from the Poke3D dataset, where each card's artwork was pre-processed with Hunyuan3D-2.1 to produce a PBR-compliant mesh and texture. By decoupling generation from real-time capture, the system ensures consistent quality and sub-second latency. Qualitative evaluation on Pokemon cards demonstrates accurate spatial alignment, coherent shape generation, and responsive interaction across lighting conditions.

Why From Cards to Creatures

No Markers, No SDKs

Detection relies on the printed set and collector number already present on official cards. No visual markers are embedded in the artwork and no proprietary tracking libraries are required, making the system portable and free of licensing constraints.

Decoupled Generation and Rendering

Hunyuan3D-2.1 produces 3D assets offline from curated, background-free artwork crops. At inference time only retrieval and rendering occur, yielding consistent quality regardless of camera noise, lighting, or occlusion.

Scalable to Any Domain

The pipeline is domain-agnostic. Although demonstrated on Pokemon TCG, it extends naturally to educational flashcards, museum exhibits, custom card games, or any domain where physical artifacts should bridge to interactive 3D content.

Method

  1. Poke3D dataset construction (offline) -- retrieve high-resolution card scans and metadata from TCGdex; crop central artwork via layout templates; remove backgrounds with salient object detection; generate PBR-compliant 3D meshes with Hunyuan3D-2.1 (~5 MB per model); index each entry by set and collector number.
  2. Card detection -- a YOLOv11-based detector localizes the card in the mobile camera feed and produces a bounding box under varying lighting and viewing angles.
  3. ID extraction -- PaddleOCR reads the set name and collector number from the localized region of interest, providing the primary key for dataset lookup.
  4. 3D asset retrieval -- the extracted ID queries the local Poke3D index and returns the pre-generated mesh and texture for that specific card's artwork.
  5. AR rendering -- the retrieved 3D model is anchored over the detected card's bounding box in real-time AR, maintaining spatial alignment across perspectives.

Inference Pipeline

camera frame -> YOLOv11 -> bbox

bbox -> PaddleOCR -> card ID

card ID -> Poke3D lookup -> mesh

mesh + bbox -> AR rendering

Generation (Hunyuan3D-2.1) and perception (YOLOv11) are fully decoupled. Only retrieval and rendering run at inference time, enabling sub-second latency on consumer-grade mobile hardware.

Contributions

Markerless AR system for physical trading cards

An interactive AR pipeline that bridges physical cards and 3D generative content using YOLOv11 detection and OCR on printed identifiers, without modifying card artwork or depending on proprietary tracking libraries.

Poke3D dataset

The first dataset covering all cards from the current Pokemon TCG series, providing high-resolution scans, gameplay metadata, background-free illustrations, and a Hunyuan3D-2.1 generated 3D model for each card.

Decoupled perception and generation pipeline

Card ID-based retrieval of pre-generated assets separates the 3D generation stage from real-time image capture, ensuring consistent mesh quality regardless of runtime camera noise, lighting, or occlusion conditions.

End-to-end mobile deployment

Sub-second retrieval and rendering on consumer-grade mobile hardware without edge-cloud dependencies, demonstrated as a working AR application with the complete current Pokemon TCG card series.
