From an initial panoramic scaffold, the remembered environment is progressively rebuilt through explicit insertion and adjustment of spatial cues, illustrating reconstruction as an active and editable process rather than passive replay.

Abstract

Human spatial memory is reconstructive rather than veridical, relying on partial cues, prior knowledge, and iterative refinement. Existing XR memory systems largely emphasize capture fidelity and replay, offering limited support for this constructive process. We present a VR system that frames spatial memory recall as interactive scene reconstruction through explicit editing operations. The system treats a remembered environment as an editable spatial artifact, supporting insertion, movement, cloning, and deletion of scene elements. A hybrid approach combines a 360° panorama as an egocentric contextual scaffold with manipulable 3D objects for fine-grained spatial adjustment, alongside localized panorama editing for correction and suppression of background elements. By operationalizing reconstruction as a sequence of visible edits, this work provides a foundation for studying how XR tools shape remembered spatial scenes.

Why This Approach

Reconstruction Is Not Replay

Human remembering assembles scenes from partial cues guided by schemas, producing adaptive generalization and systematic distortions. Passive replay cannot model this. Explicit editing operators match how reconstruction already proceeds under uncertainty.

Hybrid Egocentric and Allocentric Representation

A 360° panorama reinstates view-based context supporting recall, while a 3D object grid supports allocentric, layout-first reasoning. Both modes share the same four reconstruction operators for consistent behavioral analysis.

Deletion as a First-Class Operation

Reconstruction is not purely additive. Suppressing misleading details is as cognitively meaningful as inserting missing ones. The system treats panorama deletion as a primary operation, not visual cleanup.

Method

  1. Select a starting point: a 360° panorama from a library or generated by voice prompt (Skybox AI), providing an egocentric scaffold that reinstates layout and background cues.
  2. Insertion -- introduce a new manipulable 3D cue via voice description; the prompt is transcribed by Whisper, used to generate an object image (NanoBanana), and converted to a textured mesh (Hunyuan3D 2.1) inserted into the scene.
  3. Movement -- adjust a 3D object's position, orientation, and depth to refine spatial relations misaligned with the panorama structure.
  4. Cloning -- select a cubemap region from the panorama, extract and background-remove the patch, convert to a reusable 3D asset stored in the inventory.
  5. Deletion -- select a panorama region, apply instruction-guided inpainting to remove the target, reintegrate the edited patch into the cubemap, suppressing misleading contextual cues.
  6. As an alternative to panorama mode, a 3D grid supports allocentric, layout-first reconstruction without a background layer.

Reconstruction Operators

insertion -> schema-guided completion

movement -> spatial relation refinement

cloning -> cue externalization

deletion -> detail suppression

The four operators correspond to distinct cognitive processes in constructive remembering. Generative components (Hunyuan3D, NanoBanana) are enabling technology; the reconstruction grammar is the primary contribution.

Contributions

Interaction grammar for spatial memory reconstruction

A formal vocabulary of four first-class reconstruction operators: insertion, movement, cloning, and deletion, that make the constructive process of spatial recall explicit, observable, and analyzable.

Hybrid reconstruction approach

Combines a 360° panorama as an egocentric contextual scaffold with manipulable 3D object cues for fine-grained spatial adjustment, supporting both view-based context and layout-first allocentric reasoning within a single system.

Localized panorama editing workflow

Enables removal and correction of scene elements as part of the reconstruction process, treating suppression of background details as a memory operation rather than visual cleanup.

Foundation for behavioral XRMemory research

By making reconstruction actions traceable, the system enables future empirical study of how particular edits influence spatial recall, confidence, and reinterpretation of remembered environments under controlled conditions.
